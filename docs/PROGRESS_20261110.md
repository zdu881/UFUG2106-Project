## Reproduce

From the project root, with C++17 and Python 3 + NumPy:

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/evaluate_release.py --output results/a-new-run
```

The output directory must be new. Inspect `manifest.json`, `official.csv`,
`independent.json`, and the per-step logs. PASS requires all commands to succeed
and the complete case set to pass; missed delay targets are counted separately.
Keep the manifest and raw outputs when moving to another machine.
